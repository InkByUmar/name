# **App Name**: Stylish Glyph

## Core Features:

- Live Stylizer: Transforms user input in real-time into over 80 stylish fonts and symbol combinations optimized for gaming IDs.
- AI Alias Generator: An AI-powered tool that generates creative gamer tags based on user interests, favorite games, or personality traits using logic to suggest the best nicknames.
- Game-Specific Presets: Filtered tabs for specific games like PUBG, BGMI, and Roblox, ensuring text characters used are compatible with those platforms.
- One-Tap Copy System: Instant clipboard functionality for every generated style for rapid implementation in game profiles.
- Trending Styles Feed: A dynamic gallery displaying currently popular names and recently copied combinations used by the community.
- Gamer Identity Storage: Saves favorite generated names and recent history locally to help users manage multiple identities.

## Style Guidelines:

- A dark gaming theme with a Primary neon purple (#A200FF) for energy, an electric Cyan accent (#00E1FF) for contrast, and a deep space-black background (#09030E).
- Headline font: 'Space Grotesk' (sans-serif) for a tech-heavy, futuristic look. Body font: 'Inter' (sans-serif) for high legibility at small sizes on mobile.
- Sharp, angular stroke icons with glowing SVG filters to match the neon aesthetic, focusing on game controllers and futuristic symbols.
- Single-page dashboard layout with a focused central input area and a masonry grid for style results.
- Pulsing glow effects on hover and 'breathing' neon borders for interactive buttons and inputs.
